## 项目概览

- **项目名称**：高校科研实验室管理系统（LMS）
- **项目定位**：轻量化、场景化、数智化的一体化实验室管理平台
- **核心价值**：资源盘活 · 数据沉淀 · 安全可控 · 决策有据
- **目标用户**：高校院系科研实验室 / 公共实验中心

## 快速开始

1. 阅读 `01-业务挖掘-需求分析.md` 了解业务全貌；
2. 查看 `02-行业分析` 了解市场机会；
3. 对照 `03/04 流程图` 理解现状与转型差异；
4. 查看 `05 报价单` 与 `06 设计方案` 了解落地方案；
5. 双击打开 `07-MVP原型.html` 体验可运行的最小原型。

## 说明

本仓库文档为项目前期规划阶段的交付物，MVP 原型为纯前端单文件实现（数据存储于浏览器 localStorage），用于快速验证核心业务闭环，后续可基于 `06-设计方案.md` 进行完整开发。
